# Advanced Calculator

A feature-rich, modern calculator built with HTML, CSS, and JavaScript. This calculator supports both basic arithmetic and advanced scientific operations.

## Features

### Basic Operations
- Addition, Subtraction, Multiplication, Division
- Decimal number support
- Percentage calculations
- Number negation (+/−)

### Scientific Functions
- **Square Root** (√)
- **Power** (x²)
- **Factorial** (n!)
- **Trigonometric Functions** (sin, cos, tan) - in degrees
- **Logarithmic Functions** (log, ln)
- **Exponential** (e^x)
- **Reciprocal** (1/x)
- **Pi** (π) constant

### Memory Functions
- **MC** (Memory Clear) - Clear the memory
- **MR** (Memory Recall) - Recall the stored value
- **M+** (Memory Add) - Add current value to memory
- **M−** (Memory Subtract) - Subtract current value from memory

### Additional Features
- **Calculation History** - View all previous calculations
- **Persistent History** - History is saved in browser's localStorage
- **Mode Toggle** - Switch between Basic and Scientific modes
- **Keyboard Support** - Full keyboard support for calculations
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Beautiful UI** - Modern gradient design with smooth animations

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Number input |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| . | Decimal point |
| Enter / = | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear all (AC) |

## How to Use

1. Open `index.html` in a web browser
2. Start entering numbers and operations
3. Click the equals button (=) or press Enter to see the result
4. View your calculation history on the right side
5. Click any history entry to use that result
6. Use memory buttons to store and recall values
7. Toggle between Basic and Scientific modes as needed
